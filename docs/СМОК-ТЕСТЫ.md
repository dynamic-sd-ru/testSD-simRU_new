# Смок-тесты: от сборки до концовки

Раньше «смок-тест» останавливался на первых экранах: проверялось, что игра
загружается и что кнопка «Продолжить» существует. Из-за этого не был виден
дефект, который полностью блокировал игру. Теперь тест проходит партию
**до концовки**.

## Что было сломано

После любого события (месяц закончился, карточек нет) игра уходила в пустую
служебную сцену `post_event.events_choice`, показывала единственную кнопку
«Продолжить», и по нажатию **ничего не происходило** — партия застревала на
первом же месяце.

Причина — рассинхронизация строк:

* движок добавляет кнопку сам, и `scripts/localize-engine.js` переводил её как
  `Continue...` → `Продолжить` (без многоточия);
* `post_event.scene.dry` определяет, есть ли в колоде события, сравнивая
  заголовок первого варианта со списком: `"Продолжить…"`, `"Продолжить..."`,
  `"Continue..."`, `"Continue…"`. Варианта `"Продолжить"` в списке не было,
  поэтому `Q.has_event` **всегда** становился `1`, и игра уходила в
  `events_choice` вместо `main`. У этой сцены нет `go-to`, её единственный
  вариант — «Продолжить», который ведёт в `root` → снова `post_event` → снова
  `events_choice`. Внешне: кнопка нажимается, экран не меняется.

Исправлено с двух сторон:

1. `scripts/localize-engine.js` теперь даёт `Продолжить…` — как в остальных
   сценах игры (там везде `Продолжить…`), и как было в оригинале
   (`Continue...` с многоточием);
2. в `post_event.scene.dry` проверка переписана на список вариантов
   (`var continue_titles = ["Продолжить", "Продолжить…", "Продолжить...",
   "Continue", "Continue...", "Continue…"]`) — теперь она не зависит от того,
   с многоточием строка или без. Заодно убран мусорный `Q.has_tutorial_even`.

## Заодно локализованы строки движка

Их не было в исходниках игры, поэтому они оставались английскими:

| строка движка | стало |
| --- | --- |
| `Continue...` (кнопка) | `Продолжить…` |
| `Game Over` | `Игра окончена` |
| `Game Over (reload to read again)` | `Игра окончена (перезагрузите страницу, чтобы прочитать снова)` |
| `No cards available from deck.` | `В колоде нет доступных карточек.` |
| кнопки слотов сохранения `Load` / `Save` / `Empty` | `Загрузить` / `Сохранить` / `Пусто` |
| `Saved.` / `Loaded.` / `No save available.` / `Saving and loading is currently disabled.` | `Сохранено.` / `Загружено.` / `Сохранение не найдено.` / `Сохранение и загрузка сейчас отключены.` |

## Как запускать

```bash
npm ci                     # ставит и jsdom (devDependencies)
npm run smoke:build        # compile + make-html + game.json рядом с index.html
python3 -m http.server 8099 --directory out/html --bind 0.0.0.0

# партия до концовки (url, максимум шагов, seed)
node tools/smoke_play.js http://127.0.0.1:8099/index.html 2500 3
```

`npm run smoke` — то же без аргументов (по умолчанию `http://127.0.0.1:8099`).

Дополнительно:

```bash
node tools/smoke_walk.js  http://127.0.0.1:8099/index.html 12   # первые экраны
node tools/smoke_continue.js http://127.0.0.1:8099/index.html   # кнопка «Продолжить»
node tools/sim1934.js source/scenes/events/death_of_hindenburg_president.scene.dry
```

## Что делает `tools/smoke_play.js`

* стартует игру из главного меню (в т.ч. через экран «Пожалуйста, прочитайте»);
* каждый месяц берёт карту из колод (колоды чередуются), разыгрывает её,
  нажимает «Продолжить…», отвечает на события — выбор детерминирован seed'ом;
* следит за застреванием: если сцена и текст не меняются 40 шагов подряд —
  печатает сцену, дату и доступные варианты и падает;
* распознаёт концовку: меню `game_over.eg_menu` → «Посмотреть финальные
  слайды» → чтение концовки → «Закончить игру» → экран «Игра окончена»;
* собирает латинские фрагменты, попавшие в интерфейс (для контроля перевода);
* игнорирует ограничения jsdom (проигрывание звука/видео, внешние iframe);
* код возврата `0` только если партия дошла до концовки и ошибок JS нет.

## Результаты прогонов

| сборка | seed | дошёл до | концовка | ошибки JS |
| --- | --- | --- | --- | --- |
| рабочая | 1 | 1930-12 | Власть Гитлера неоспорима | нет |
| рабочая | 3 | 1931-05 | да | нет |
| рабочая | 5 | 1933-05 | да | нет |
| рабочая | 7 | 1931-08 | Гражданская война проиграна | нет |
| чистая (`npm ci` + `npm run smoke:build`) | 2 | 1931-05 | да | нет |
| чистая | 3 | 1932-03 | да | нет |

Концовки у игры разные (их больше двадцати), поэтому «дошёл до конца» — это
экран `game_over.eg_menu` с «Конец» и кнопкой «Закончить игру», а затем
`Игра окончена`. Все прогоны выше доходят именно до него; до этого партия
проходит выборы 1928, 1930 и 1932 годов, кризисы, вотумы и смену кабинетов.

Латинские фрагменты, которые тест находит в интерфейсе, — это названия
(мод «Dynamic Social Democracy», немецкие заголовки статей, песен и плакатов:
`Panik im Mittelstand`, `Die Rote Fahne`, `Einigkeit und Recht und Freiheit`
и т. п.). Их не переводят, это подписи произведений.
