# Сборка, GitHub Actions и ассеты

Документ описывает, как проект собирается на GitHub и что лежит в репозитории,
чтобы сборка не затирала перевод и картинки.

## 1. Что исправлено в `.json` / `.yaml`

### `package.json`

| было | стало | зачем |
| --- | --- | --- |
| `repository/bugs/homepage` → `socdemtestmode/testSD-simRU` | `dynamic-sd-ru/testSD-simRU_new` | ссылки вели на старый репозиторий |
| `"dendrynexus": "github:originn0/dendrynexus"` | `github:originn0/dendrynexus#142d0d8` | воспроизводимая сборка: движок фиксируется по коммиту |
| — | `"engines": { "node": ">=20" }` | Node 16 на раннерах устарел |
| — | `"private": true`, описание | проект не публикуется в npm |
| `make-html` | `… && npm run check-html` | после сборки проверяется, что переведённый `index.html` на месте |
| `build` | `… && npm run check-html` | то же для `compile` |

### `package-lock.json`

* git-зависимость движка была записана как ssh-ссылка
  (`git+ssh://git@github.com/originn0/dendrynexus.git`) — на раннере GitHub
  Actions нет ssh-ключа, установка падала. Теперь:
  `git+https://github.com/originn0/dendrynexus.git#142d0d85…` + `integrity`.
* `npm ci` с этим локом проверен: 282 пакета ставятся, `postinstall`
  локализует строки движка.

### `.github/workflows/build.yaml`

* `node-version: 16` → **20** и `cache: npm`.
* `npm install` → **`npm ci`** (ставит ровно то, что в локе).
* добавлен шаг **`npm run build`** (`dendrynexus compile`): ошибки сцен видны
  до публикации, а не после.
* `npm run dendrynexus make-html -- --pretty` → **`npm run make-html`** (то же
  плюс локализация строк движка и проверка html-обвязки).
* `NODE_OPTIONS=--max-old-space-size=4096` — `core.js` собирается браузерифай
  и на больших сценах упирается в память.
* сборка и публикация разнесены на два job'а (`build` → `deploy`), артефакт
  передаётся через `actions/upload-pages-artifact`.

## 2. `index.html` не перезаписывается сборкой

В шаблоне движка файлы `+index.html`, `+game.css`, `+game.js` копируются в
`out/html` **только если таких файлов там ещё нет** (`copyTemplate` в
`dendrynexus/lib/cli/utils.js`). Поэтому переведённый `out/html/index.html`
лежит в репозитории и сборка его не трогает — то же поведение, что и в
оригинальной игре. Опасен только запуск с флагом `--overwrite`; от него
страхует `npm run check-html` (`scripts/check-html-assets.js`): если в
`index.html` пропали русские подписи, шаг падает с подсказкой
`git checkout -- out/html/index.html`.

Проверено: после `npm run build` и `npm run make-html` контрольные суммы
`index.html`, `game.css`, `game.js` не меняются.

Что переведено в `index.html`: меню настроек (фон, изображения, анимации,
музыка, тема, цветной текст), сохранения, вкладки левой панели и подпись
авторов. В этом обновлении дополнительно: `lang="ru"` и вкладка правой панели
«Интриги» (в оригинале — `Scheming`).

## 3. `game.css` и `game.js`

Перевода в них нет (проверено: кириллицы в файлах нет), но лежали они в
репозитории в старой версии — от движка до появления модов. Из-за этого
переведённый `index.html` (он соответствует upstream `307d5473`) обращался к
`window.showMods()`, которого в старом `game.js` не было. Файлы приведены к
версии upstream `307d5473`: кнопки модов и загрузки мода снова работают,
стили тёмной/светлой темы совпадают с оригиналом.

сборка её не создаёт, а сцены ссылаются на `img/...` (389 ссылок).

* восстановлено **401 файл** из истории перевода (`047adac`), т.е. именно
  исправленные картинки (106 портретов, 118 иконок достижений, постеры,
  фоны, флаги);

  было: 6 новых иконок достижений (`die_rote_justiz`, `merz_und_scholz`,

## 5. Что теперь игнорируется git'ом

`.gitignore` приведён к подходу оригинала — в репозитории лежит вся обвязка
игры, а генерируемое исключено:

```
/node_modules
out/game.json
out/html/game.json
out/html/core.js
out/html/jquery-1.11.1.min.js
```

Раньше `out/` игнорировался целиком, из-за этого новые файлы `img` не попадали
в коммит.

## 6. Как проверить локально

```bash
npm ci                 # ровно то, что в package-lock.json
npm run build          # компиляция + проверка обвязки
npm run make-html      # сборка HTML (index.html остаётся переведённым)
cp out/game.json out/html/game.json
python3 -m http.server 8099 --directory out/html --bind 0.0.0.0
node tools/smoke_walk.js http://127.0.0.1:8099/index.html 8
node tools/smoke_continue.js http://127.0.0.1:8099/index.html
```
