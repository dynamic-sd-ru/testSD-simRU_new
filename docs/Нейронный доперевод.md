# Нейронный доперевод

Документ фиксирует всё, что в этой сборке переведено **заново** (в готовом
переводе этих строк не было либо они там оказались потеряны), и объясняет,
почему остальное переводить не пришлось. Правило проекта прежнее: сначала
ищем готовый перевод — пусть даже «съехавший» — и только если его нет,
переводим сами, строго в стиле существующего перевода.

## 1. Откуда взялся новый текст

| источник | объём |
| --- | --- |
| новые файлы upstream (`afa_formed`, `sapd_toleration_prussia_collapse`, `workers_aid_unpopularity`, `bdf_cooperation`, `new_middle_consciousness`, `rural_consciousness`, `vote_of_no_confidence_constructive`) | 7 файлов, ~13 400 слов |
| новый текст внутри уже переведённых сцен (Antifa, взаимопомощь, вотум недоверия, требования КПГ, CVP-коалиция, достижения) | 81 фрагмент |
| строки, которых не было в сборке из-за перестройки upstream | 27 «stale» + 16 пропущенных reflow-блоков |

## 2. Методика: как искали готовый перевод

1. **`tools/carry_similar.py`** — для новых файлов, которые являются почти
   копиями уже переведённых сцен (карта доноров:
   `tools/maps/similar_donors.json`). Оттуда перенесено **153 строки**
   (например, `sapd_toleration_prussia_collapse` ← `prussian_coalition_formation`,
   `vote_of_no_confidence_constructive` ← `vote_of_no_confidence`,
   `workers_aid_unpopularity` ← `reichsbanner_unpopularity`).
2. **`tools/assemble.py` → `split_joined()`** — перевод иногда держит целый
   блок строк upstream на одной строке. Блок разрезается по «якорям» разметки
   (`[? if …`, `[+ … +]`, цвета `<span>`), причём якоря сверяются выравниванием
   `difflib` (потеря пары якорей больше не ломает весь блок). Порезка с
   оборванной разметкой отклоняется целиком — лучше оставить английскую
   строку, чем испортить сцену. Это вернуло перевод в `status`, `library`,
   `modinfo`, `economic_policy`, `party_disunity` и др.
3. **`tools/apply_neo.py` + `tools/maps/neo_ru.json`** — карта «английская
   строка → русская строка» для действительно новых строк. Совпадение только
   по целой строке (с учётом префиксов `- @anchor:`, `title:`, `subtitle:`),
   поэтому ни один перевод не применяется дважды и разметка не страдает.

## 3. Что переведено вручную

Карта собрана из `work/neo/part_a.py` (строки 0–79), `part_b.py` (80–153) и
`part_c.py` (точечные правки). Всего **173 записи**; в сборке применено
**229 замен** (одна и та же строка встречается в нескольких файлах).

Тематически:

* **Antifa / «Железный фронт»** — карточка создания
  `Antifaschistische Aktion`, запрет СА («Запретить <span …>**СА**</span> —
  <span …>нацистскую</span> военизированную организацию»), реплики о
  координации с КПГ, опция «Промолчать насчёт этой массовой организации».
* **AfA-bund, Бааде, Юхач** — пробуждение классового самосознания нового
  среднего класса, крестьянства и сельских рабочих; переговоры с
  *Bund Deutscher Frauenvereine*; карточки `bdf_cooperation`,
  `new_middle_consciousness`, `rural_consciousness`.
* **Конструктивный вотум недоверия** — «Вынести конструктивный вотум
  недоверия!», «У нас есть большинство и без них», «Из-за конституционных
  реформ они не могут вынести вотум недоверия, но будут мешать нашему
  правительству при любой возможности».
* **Требования КПГ** — «Улучшить наши отношения с <span …>Советским
  Союзом</span>», «Запретить **СА** и **Стальной Шлем**», «Защитить
  коммунистические демонстрации».
* **Достижения** — подписи пяти новых ачивок (`Der Rote Justiz`,
  `Brüning der Rotfrontkämpfer`, `Merz und Scholz`, `Lindner Moribund`,
  `Tausendjährige Libreich`): названия оставлены немецкими каламбурами, как в
  оригинале, а подписи переведены в стиле существующих.
* **Прочее** — Саксония-1933 (АСПД, Хельдт, Винниг, Никиш, Бук), смерть
  Гинденбурга (кандидатура Курта Шумахера), «Браун избран
  министром-президентом Пруссии», съезды партий, лондонская конференция,
  мелкие опции («Мы этого не сделаем»).

Термины и имена взяты из готового перевода: Ауфхойзер, Бааде, Юхач, Брюнинг,
Шлейхер, Папен, Штегервальд, Хаммерштейн, Штрассер, Гёрделер, Тревиранус,
Бредов, Шумахер, Стреземан, РФБ, СКФ, «Стальной Шлем», Рейхсвер,
«Имперская экзекуция», «белые воротнички», «терпимость», «досрочные выборы».

## 4. Исправления испорченных мест готового перевода

Найдены сверкой с оригиналом; внесены в `tools/maps/tr_fixes.json`
(`tools/fix_tr_breaks.py`):

1. `government_affairs/red_general` — в переводе от абзаца остался обрывок
   «Хотя <span …>[? if chancellor_party == "СДПГ": СДПГ ?]»: текст письма был
   потерян. Абзац переведён заново (обе ветки условия, АДГБ, «Красный
   генерал»).
2. `events/papen_altona_clashes` — подзаголовок с вложенным `<span>` и
   «разъехавшимся» жирным: `<span>**Демонстрация <span>СА**</span>` →
   `<span>**Демонстрация СА**</span>, которая может обернуться насилием`.
3. `events/thuringia_reichsexekution_popular` — незакрытый `<span>` вокруг
   названия партии: «назначает <span …>члена **ХНПКЗ**</span> Эрвина Баума».

## 5. Единообразие переменных

* `tools/maps/party_values.json` (новый) закрывает пробелы карты значений для
  служебных переменных состава правительства: `*_minister_party`,
  `chancellor_party`, `treviranus_party`, `vorbeck_party`, `westarp_party`,
  `z_party_name`. Раньше в сборке оставались английские сравнения
  (`labor_minister_party == "BVP"` и т. п.) — теперь их нет.
* `tools/apply_display_names.py` (новый) заменяет «забытые» жирные метки
  партий в тексте (`**DNEF**` → `**ФНЕГ**`, `**Stahlhelm**` →
  `**Стальной Шлем**`, `**Others**` → `**Прочие**`, `**FKP**` → `**СКП**`).
* `tools/fix_candkeys.py` дополнен картой `candkey()`: кандидаты на выборах
  1934 года хранятся в русских переменных, но `_votes`, `_running`, `_bonus`
  адресуются по латинским ключам (`Hitler_votes`, `Gessler_votes`, …).
  Проверено симуляцией: все кандидаты учитываются, победитель считается
  (Эккенер 27,5 › Гитлер 22,4 › Аденауэр 15,1 › Тельман 14,2 › Гесслер 11,7 ›
  Зельдте 9,1).

## 6. Что осознанно оставлено на английском

| место | почему |
| --- | --- |
| `scenes/credits.scene.dry`, библиография в `modinfo` | список литературы и ссылки на источники — так же в готовом переводе |
| названия достижений (`Die Rote Justiz`, `Merz und Scholz`, …) | немецкие каламбуры, в переводе не переводятся |
| `Title: Subending …` в `ending_slides`, `Title:` в `election_1928` | технические метки слайдов, сохранены как в переводе |
| строки, начинающиеся с `#` | комментарии кода upstream, игроку не показываются |
| `_candidate`, `_support`, `_normalized` в таблицах выборов | служебные ключи партий (ASCII), отображается только результат |

## 7. Проверки после доперевода

* `tools/build.sh` — сборка без пропусков; `node … compile` — код 0.
* `make-html --pretty` + headless-прогон (`tools/smoke_walk.js`,
  `tools/smoke_continue.js`): меню, первые сцены, кнопка «Продолжить», ошибок
  JS нет (кроме штатного предупреждения jsdom про `play()`).
* Баланс разметки по всем сценам: `[?` = `?]`, `[+` = `+]`, `<span>` =
  `</span>` (единственные расхождения — три «лишних» `</span>`, которые есть
  и в оригинале upstream).
* `tools/sim1934.js` на трёх сценах выборов 1934 года — все кандидаты
  отображаются и учитываются.
