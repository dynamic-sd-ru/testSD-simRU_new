- Названия партий возвращены к вариантам перевода (`**SPD**` → `**СДПГ**` и т.д.)

## Экран результатов выборов (найдено сквозным смок-тестом)

`scenes/events/election_1928.scene.dry` — блок `post_election_1928`:

- перевод заменил среднюю из трёх кнопок плашкой с тремя русскими кнопками, а
  две соседние (сырой HTML в `{! ... !}`) остались английскими. На экране было
  пять кнопок, две из них английские и с повторяющимися `id`
  (`graph_tab`, `demographics_tab`) — переключение вкладок работало
  непредсказуемо. Теперь три русские кнопки и по одному `id` на каждую.
- таблица демографических результатов существовала дважды: исходная
  английская (`<th>Party</th>`, `<th>Workers</th>`, …) и добавленная переводом
  русская копия в конце блока. Английская копия удалена, русская оставлена
  (структура проверена: те же 182 переменные и 90 условий), `<svg>` для
  графиков сохранены в одном экземпляре.

`scenes/mod_loader.scene.dry`: кнопка `<button id="submit">Submit</button>`
теперь «Загрузить».

Проверка повторяется скриптом `tools/audit_magic.py` (ищет латиницу в видимом
тексте всех блоков `{! ... !}` в собранном `out/game.json`; сейчас — 0
фрагментов).
