# Отчёт о переносе перевода на актуальную версию игры

## Что взято за основу

| роль | источник |
| --- | --- |
| перевод (источник текста) | этот репозиторий, `source/` |
| версия игры, для которой был сделан перевод | upstream `60d02d0e` (апрель 2026) |
| актуальная версия игры | upstream `307d5473` (25 октября 2026) |

Новых текстов не переводили: всё, чего не было в готовом переводе, осталось
на английском и перечислено в `НЕПЕРЕВЕДЁННЫЙ_ТЕКСТ.md`.

## Как собран результат

`source/` собран программно: **структура и код — из новой версии игры, реплики,
заголовки, варианты ответа и подписи — из перевода**. Скрипты сборки лежат в
`tools/` (`tools/build.sh` — весь конвейер одной командой), отчёты о каждом шаге —
в `tools/reports/`.

## Контроль полноты переноса

`tools/audit_cov.py` вытаскивает из перевода все русские фрагменты (33 316 штук)
и ищет их в собранном дереве.

* перенесено: **33 299** (99,95 %);
* не найдено: **17** — все относятся к содержимому, которое upstream удалил или
  переименовал (сцены `@muller`, `@resultsdvp`, опция `@civil_war`, партия СКП,
  переименованная в FKP, и подсказки, заменившиеся новыми строками игры).

Крупные структурные поломки перевода, мешавшие сборке, перечислены в
`ИСПРАВЛЕНИЯ_ПЕРЕВОДА.md`; все правки слипшихся слов — в
`ИСПРАВЛЕНИЯ_ПРОБЕЛОВ.md`.

## Выборы 1934 года

Блоки выборов пересобраны с сохранением русского текста, но с ключами переменных
upstream (`candkey()`), поэтому голоса снова попадают в те же переменные, что
читает остальная игра.

Результат симуляции (`tools/sim1934.js`, сцена `death_of_hindenburg_president`):

| кандидат | голоса |
| --- | --- |
| Эккенер | 27,5 |
| Гитлер | 22,4 |
| Аденауэр | 15,1 |
| Тельман | 14,2 |
| Гесслер | 11,7 |
| Зельдте | 9,1 |

Агрегаты по блокам (Центр 15,1 / Либералы 11,7 / Правые 9,1) тоже считаются,
все кандидаты отображаются в результатах.

## Сборка и смок-тесты

```
npm install          # postinstall локализует строки движка («Continue» → «Продолжить»)
npm run build        # компиляция: 0 ошибок, out/game.json ~11,2 МБ
npm run make-html    # out/html/index.html
```

Проверено:

* `dendrynexus compile` — без ошибок;
* `dendrynexus make-html --pretty` — собирается;
* загрузка собранной HTML-версии в headless-браузере (jsdom) — игра
  стартует, меню и первые сцены на русском, ошибок JS нет;
* кнопка «Продолжить» приходит из локализованного движка, в бандле
  `out/html/core.js` нет английской подписи.

## Что осталось на английском

См. `НЕПЕРЕВЕДЁННЫЙ_ТЕКСТ.md`: 166 непереведённых реплик/подписей, 81 строка
нового текста в существующих сценах, 7 новых файлов upstream и 5 новых
достижений (всего 15 строк таблицы достижений).
