# Состояние работы

Перевод перенесён на актуальную версию игры (`upstream 307d5473`), сборка
компилируется и запускается. **Непереведённого текста в игре больше нет** —
всё, чего не было в готовом переводе, допереведено (см.
`docs/Нейронный доперевод.md`).

* **Готово:** `source/` — собранное дерево (структура/код новой версии, тексты
  перевода); `docs/` — отчёты; `tools/` — конвейер сборки и карты значений;
  `out/` — результат `npm run build` и `npm run make-html`.
* **Полнота переноса:** 33 299 из 33 316 русских фрагментов (99,95 %), остаток —
  только удалённое/переименованное upstream (см. `docs/ОТЧЁТ_О_ПЕРЕНОСЕ.md`).
* **Доперевод:** 7 новых файлов upstream и 81 новый фрагмент в старых сценах
  закрыты в два шага — сначала перенос из похожих переведённых сцен
  (`tools/carry_similar.py`, 153 строки) и восстановление «слипшихся» блоков
  (`split_joined` в `tools/assemble.py`), затем ручной перевод реально новых
  строк (`tools/maps/neo_ru.json`, 173 записи, собраны из `tools/neo/`).
* **Единообразие переменных:** `tools/maps/party_values.json` (значения
  `*_party`, `z_party_name`), `tools/apply_display_names.py` (жирные метки
  партий), карта `candkey()` в выборах 1934 года.
* **Проверки:** компиляция без ошибок (`compile` — код 0); `make-html`
  собирается; headless-загрузка HTML-версии проходит (`tools/smoke_walk.js`,
  `tools/smoke_continue.js`, кнопка «Продолжить»); баланс разметки
  `[? ?]`, `[+ +]`, `<span>` по всем сценам; симуляция выборов 1934 года на
  трёх сценах — все кандидаты отображаются и учитываются
  (Эккенер 27,5 › Гитлер 22,4 › Аденауэр 15,1 › Тельман 14,2 › Гесслер 11,7 ›
  Зельдте 9,1).
* **Строки движка:** `scripts/localize-engine.js` (запускается из `postinstall`)
  заменяет «Continue…» на «Продолжить».

Пересборка: `ROOT=/home/user bash tools/build.sh /path/out` (нужны деревья
`base`/`new`/`tr2` upstream — см. комментарий в начале скрипта), затем
`npm run build && npm run make-html`. Карта доперевода пересобирается
`python3 tools/neo/build_map.py` (переменная `NEW_SRC` — путь к исходникам
upstream).
